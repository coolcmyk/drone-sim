Interactive Drone Sim Pod for Fern

Fern now creates a fresh Runpod GPU Pod with an immediately available, password-protected noVNC desktop. The user starts the simulator from its terminal rather than requiring Docker inside the Pod.

Operator hand-off

/opt/drone-sim/scripts/sim_up_local.sh --detach

The local launcher starts Unreal/Cosys-AirSim, Micro-XRCE-DDS Agent, QGroundControl and PX4 SITL. QGroundControl reuses the desktop, while MAVLink, DDS, AirSim RPC and raw VNC remain Pod-local.

Build constraint

Jazzy is source-built on the UE-compatible Jammy base. Its build is limited to the runtime dependency closure and the Fern publisher reclaims unused GitHub-hosted-runner disk before Buildx.

Verification status

Shell syntax and diff validation passed. End-to-end image build, Fern deployment, browser noVNC and readiness-gate verification remain pending the published image.
